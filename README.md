# Calibrated Probabilistic Graphlets

Gene function prediction from calibrated probabilistic graphlets in a monocyte co-expression network

Author: Michelle Gandidzanwa ([ORCID 0009-0004-1593-1446](https://orcid.org/0009-0004-1593-1446))

## Project proposal

Do graphlet features from a calibrated probabilistic gene co-expression network predict gene function better than features from thresholded (binary) networks?

I will use single cell RNA-seq of PBMCs from 8 donors (Kang et al. 2018, NCBI GEO GSE96583). There are no restrictions on use from GEO and Gene Ontology annotations (CC BY 4.0). For CD14+ monocytes I estimate each edge's probability by resampling cells within donors and calibrating it against replication in independent donors, compute probabilistic graphlet degree vectors and compare them with binary graphlet features for predicting GO biological process terms. Expected outputs: a calibration plot, network summaries, a table and figure of prediction performance (AUPR) for each feature set and a Quarto report.

### Data availability statement

The single-cell RNA-seq data analysed here are publicly available from NCBI GEO under
accession GSE96583 (Kang et al. 2018); this project uses samples GSM2560248 and
GSM2560249 and the batch-2 gene and cell metadata files. Gene Ontology annotations and
ontology are from the Gene Ontology release of 2026-08-05 (CC BY 4.0). The exact URLs and
SHA-256 checksums of all raw files are in `metadata/sources.tsv` and
`metadata/checksums.sha256`, and `scripts/download.sh` retrieves them. Raw data are not
redistributed in this repository. All derived results are regenerated from the raw data
by the code in this repository.

### Responsible use of human data (CARE)

The expression data come from human donors and were deposited by the original study in
de-identified, processed form for research. This project uses only those processed
counts and the published cell annotations, reports results only at the level of genes
and a cell type, and makes no attempt to identify any donor. The donors' consent terms
belong to the original study, so this repository holds code and derived results, not the
data. Anyone reusing the data should go to GEO and cite the original study.
